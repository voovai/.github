## Catalyst — every AI, one workspace

[**Catalyst**](https://catalyst.voov.ai) is an AI workspace that doesn't lock you to a provider.
Chat with any model, give it your tools and data, and turn the things that work into reusable
workflows and skills.

- **Chat** — talk to OpenAI, Anthropic / Claude, Google / Gemini, local & self-hosted models, and any custom endpoint, all in one place.
- **Workflows** — visual pipelines that turn a working prompt into something you can run again.
- **Skills** — package the way you work into reusable, parameterized building blocks.
- **Memory** — persistent context that carries across sessions.
- **Data** — connect SQL and other sources so models answer from your real data.
- **MCP** — extend any model with external tools over the Model Context Protocol.

Free · Google sign-in · No credit card.
